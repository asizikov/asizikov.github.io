Currently deployed at [blog.cloud-eng.nl](https://blog.cloud-eng.nl)


## Local development

Install Hugo 0.170.1, the version used by CI. In the GitHub Copilot app,
review and accept the repository configuration, then run the **Run** script
to start the server.

Running in CodeSpaces:

```bash
 hugo serve -b=/ --appendPort=false
```
